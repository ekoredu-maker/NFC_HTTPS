JCLA26 NFC 출결관리 HTTPS 배포용

1. 이 압축파일을 풀면 index.html이 있습니다.
2. Netlify Drop, GitHub Pages, Cloudflare Pages 등 HTTPS가 제공되는 정적 웹 호스팅에 index.html을 올립니다.
3. 안드로이드 스마트폰 Chrome에서 배포된 https:// 주소로 접속합니다.
4. NFC 쓰기/읽기 버튼을 누른 뒤 권한 요청을 허용합니다.
5. 태그를 스마트폰 뒷면 NFC 위치에 대고 테스트합니다.

주의
- file:/// 로 직접 열면 NFC 쓰기/읽기가 차단될 수 있습니다.
- Web NFC는 안드로이드 Chrome에서 테스트하세요.
- 태그에는 학생 개인정보가 아니라 JCLA26-001 같은 코드만 저장하세요.
